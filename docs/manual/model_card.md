# Model Card — Gradient Boosting para Churn

| Campo                         | Informação                                                                                                                                                                                                         |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Nome do modelo**            | Gradient Boosting 0.35 — Churn                                                                                                                                                                                     |
| **Data de treinamento**       | 22/08/2026                                                                                                                                                                                                         |
| **Algoritmo**                 | Gradient Boosting                                                                                                                                                                                                  |
| **Versionamento**             | v1.0                                                                                                                                                                                                               |
| **Threshold**                 | 0,35                                                                                                                                                                                                               |
| **Uso pretendido**            | Estimar a probabilidade de churn e priorizar clientes para ações de retenção                                                                                                                                       |
| **Saída**                     | Previsão de churn/não churn e probabilidade estimada de churn                                                                                                                                                      |
| **Performance — Accuracy**    | 0,783                                                                                                                                                                                                              |
| **Performance — Precision**   | 0,575                                                                                                                                                                                                              |
| **Performance — Recall**      | 0,696                                                                                                                                                                                                              |
| **Performance — F1-score**    | 0,629                                                                                                                                                                                                              |
| **Performance — ROC-AUC**     | 0,846                                                                                                                                                                                                              |
| **Critério de escolha**       | Maior equilíbrio entre recall, F1-score e volume de falsos positivos                                                                                                                                               |
| **Principal trade-off**       | Maior recall em troca de menor precision/accuracy                                                                                                                                                                  |
| **Limitações**                | A base não possui dados de campanhas de retenção, ofertas, custos ou resultados financeiros. Portanto, não é possível medir diretamente redução de churn, receita preservada ou ROI.                               |
| **Possíveis vieses**          | Variáveis como `gender`, `SeniorCitizen`, `Partner`, `Dependents`, `PaymentMethod` e informações de cobrança podem refletir diferenças demográficas ou socioeconômicas e gerar desempenhos distintos entre grupos. |
| **Risco de viés**             | O modelo pode apresentar taxas diferentes de falsos positivos, falsos negativos, precision ou recall entre grupos de clientes. É recomendável realizar avaliação de fairness antes e durante o uso em produção.    |
